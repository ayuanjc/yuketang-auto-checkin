## 1. 上课后（19:00 之后）

### 路线 A：全自动（推荐先等 30 秒）

任务 1 已设为 `acct=main / classroom=26000002 / 07:00–23:30 / 每天都跑 / quiz=1 / geo=1`。
调度器每 15 秒扫一次「正在上课」的课节：

- 命中正在上课 → 自动 `POST /api/v3/lesson/checkin source=5`
- 成功写一条运行记录（成功 + lessonId），900 秒内不重复签
- `quiz=1` → 自动拉起 `lesson_watch` 跟课，收到 `unlockproblem` 用 AI 作答并提交
- `geo=1` → 该课若开启位置签到，会用任务里保存的 lat/lng 走 eligibility → preview → submit

验证：概览「最近运行」出现 `成功 · status=200 {"code":0…`；或「任务」tab 看 last_result。

**注意**：任务绑定的是课堂 `26000002`（数据结构与算法 / 2026秋-计算机2515）。
如果 19:00 是**另一门课**，在「课堂」tab 找到它 → 「设为定时课堂」重建任务（同一课堂不要建两条）。临时也可以直接用路线 B 手动签。

### 路线 B：现场手动（最稳）

概览页「进行中的课堂」→ 找到这节课 → 点 **签到**。
返回 `{"ok":true,"detail":"status=200 {\"code\":0…"` 即成功。

### 路线 C：扫老师二维码（老师放出二维码时）

1. 手机开 https://example.com/ykt/ （老扫码页，需 key：`?k=yk3oorvgsj0iimmv`）
2. 「启动摄像头」→ 对准老师屏幕的二维码 → 自动识别 → 服务端回放签到 → 写 lesson_auth
3. 或概览页「兑换并签到（全部账号）」：把二维码里的 URL 粘贴进去（动态码路径）

二维码类型判断：

| 长什么样 | 能不能自动 |
|---|---|
| `…/lesson/check-in/dynamic-qr-code?c=…&t=…&s=…` | 能，`/api/v3/app/scan`（x-client: app）兑换后用 `source=21` 签 |
| 普通签到二维码（页面提示「扫码签到」） | 能，扫码页 `/api/replay` 回放 |
| 微信小程序入口（`#小程序://长江雨课堂/…`） | 不能，需在雨课堂 App 内手动签到 |

### 路线 D：位置签到（老师要求「定位签到」时）

1. 「任务」tab → 「用本机定位填入」（允许位置权限）→ 自动写入 WGS-84 坐标
2. 点 **探测本课位置规则**：返回 `needLocationSignIn:true` 才需要位置签到；`false` 说明老师没开
3. 点 **预检并提交**：`inRange:true` + `code:0` 即打卡成功；`inRange:false` 说明不在半径内，靠近一点重试
4. 坐标提交时自动 WGS-84 → GCJ-02（实测偏移约 300–600 米，必须转）

## 2. 小测（随堂题）

- 任务 `quiz=1` 时自动跟课；老师发题后 8–240 秒内（按题目限时）AI 作答并提交

## 3. 出问题怎么读

| 现象 | 含义 | 处理 |
|---|---|---|
| `code 50000 / 401 登录失效` | 该账号雨课堂会话过期 | 设置 → 扫码绑定（会覆盖旧账号，1:1） |
| `code 50070 DYNAMIC_QR_CHECK_IN_REFUSED` | 该节是动态码签到，普通签到被拒 | 走路线 C 兑换真码，`source=21` |
| `code 50027 NOT_IN_CLASSROOM` | 该账号不在这门课的班级里 | 用正确账号绑定 |
| `code 51202` | 动态码签名验证失败（假码/过期） | 重新扫老师屏幕的码 |
| `code 51210 请使用位置签到` | 该节必须位置签到 | 走路线 D |
| `inRange:false` | 不在教室半径内 | 靠近中心点重试 |
| 运行记录 `会话失效：需重新扫码` | 自动签到因会话失效跳过 | 重新扫码绑定 |
