# 接口约定（HTTP / REST）

## 1. 基础

- Base：`https://<host>/api/v1`
- 编码：JSON UTF-8；时间 ISO8601 带时区（`2026-11-16T14:00:00+08:00`）
- 鉴权：`Authorization: Bearer <access_jwt>`（15min）；刷新用 `POST /auth/refresh` 带 refresh token（30d，旋转+复用检测）
- 幂等：所有写接口接受 `Idempotency-Key` 头，24h 内重复同 key 返回首次结果
- 追踪：响应头 `X-Request-Id`，日志可查

## 2. 统一响应信封

```json
{ "code": 0, "msg": "ok", "data": { }, "request_id": "req_01H..." }
```
**成功恒 `code=0`；失败 HTTP 状态码与 code 同时表达**，前端只看 `code`。

分页：`?page=1&size=20`（size ≤ 100）→ `data: {items:[], total, page, size}`。

## 3. 错误码分段

| 段 | 含义 | 示例 |
|---|---|---|
| 1xxxx | 通用/参数/鉴权 | 10001 参数非法，10101 未登录，10102 无权限，10404 不存在，10429 限流 |
| 2xxxx | 账号绑定 | 20001 二维码过期，20002 扫码超时，20003 账号已绑定他人，20004 会话已失效需重扫，20005 该域名不支持 |
| 3xxxx | 任务/课堂 | 30001 无进行中的课堂，30002 签到已结束，30003 签到全部策略失败，30004 任务已存在（幂等命中），30005 出口代理不可用 |
| 4xxxx | 订单/计费 | 40001 余额不足，40002 服务已到期，40003 重复支付，40004 退款中 |
| 5xxxx | 协议/上游 | 50001 雨课堂接口变更，50002 上游超时，50003 上游 5xx，50004 上游限流拦截 |

**[M]** 50001/50004 必须同时打 `ops_alerts`，前端只展示"系统维护中，稍后自动重试"。

## 4. 端点清单（v1）

### 认证
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/auth/register` | 邮箱/手机 + 密码（argon2id） |
| POST | `/auth/login` | 返回 access + refresh |
| POST | `/auth/refresh` | 轮换 refresh |
| POST | `/auth/logout` | 吊销 |
| GET | `/me` | 用户 + 余额 + 订阅状态 |

### 账号绑定（核心流程）
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/accounts/bind/start` | body `{domain}` → `{bind_id, qr_url, expires_at}` |
| GET | `/accounts/bind/{bind_id}` | 轮询：`pending|scanned|confirmed|expired`；confirmed 时返回 `account_id, nickname, school` |
| GET | `/accounts` | 列表（含 `status, session_expires_at`） |
| POST | `/accounts/{id}/rebind/start` | 续期扫码（同 bind 流程） |
| DELETE | `/accounts/{id}` | 解绑，立即删除密文 |
| POST | `/accounts/{id}/verify` | 主动校验会话，返回 `{valid, expires_at}` |

### 课表与任务
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/accounts/{id}/courses` | 拉取雨课堂课程/课堂列表 |
| POST | `/schedules` | 建课表规则（cron/rrule 或 weekday+time） |
| GET | `/schedules?account_id=` | 列表 |
| PATCH | `/schedules/{id}` | 开关/改时间/改策略（`{checkin:true, quiz:"llm", geo:{lat,lng}}`） |
| DELETE | `/schedules/{id}` | |
| GET | `/lessons?account_id=&from=&to=` | 课堂执行记录 |
| GET | `/lessons/{id}/runs` | 每步执行明细（策略链逐步结果） |
| GET | `/lessons/{id}/trace` | 返回 MinIO 预签名 URL（7 天） |
| POST | `/tasks/{id}/retry` | 手动重试（ops 权限） |

### 小测
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/lessons/{id}/problems` | 题目 + 提交答案 + 置信度 + 来源 |
| POST | `/lessons/{id}/problems/{pid}/override` | 人工改答案并回填题库 |

### 订单
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/plans` | 套餐 |
| POST | `/orders` | 下单 → 支付参数 |
| POST | `/webhooks/pay/{provider}` | 支付回调（签名校验，幂等） |
| GET | `/orders` | 我的订单 |

### 运维（ops/admin）
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/ops/health` | 各进程 + pg + redis + 队列积压 + agent 心跳 |
| GET | `/ops/accounts?status=` | 全局账号状态 |
| POST | `/ops/profiles/{domain}` | 发布新协议 profile（热生效） |
| POST | `/ops/circuit/{domain}` | 手动熔断/恢复某域名族 |
| GET | `/ops/queues` | stream 深度、PEL、最老未 ack |

## 5. 内部接口（进程间，不走公网）

- `agent` 不暴露 HTTP，只消费队列（减少暴露面）。
- `api` → `scheduler`：`POST /internal/wakeup {account_id, lesson_id}`（仅 127.0.0.1 / docker 内网，共享 token）。
- `scheduler` 写 `tasks` 表 + `XADD ykt.tasks`，agent 只读队列。

## 6. 事件推送（前端 SSE）

`GET /v1/events?account_id=` → `text/event-stream`
```
event: lesson
data: {"lesson_id":123,"status":"live","checkin":"success"}
event: problem
data: {"problem_id":"p1","answer":["A"],"source":"bank","confidence":0.93}
event: alert
data: {"code":20004,"msg":"会话已失效，请重新扫码"}
```
前端断线重连带 `Last-Event-ID`，服务端回放 5 分钟窗口。
